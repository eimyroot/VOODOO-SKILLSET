# Code of Conduct

Collaboration in this repository must remain professional, constructive, and safe. Focus criticism on ideas, code, evidence, and outcomes. Harassment, discrimination, threats, intimidation, doxxing, sexualized conduct, personal attacks, or publication of private information without permission are not acceptable.

This applies to issues, pull requests, reviews, discussions, and other project-related communication.

Maintainers may remove content, close or lock conversations, reject contributions, or restrict participation when behavior violates this Code of Conduct. Report conduct concerns privately to the repository owner and do not place sensitive personal information in public issues.

Disagreement is expected. Abuse is not.
