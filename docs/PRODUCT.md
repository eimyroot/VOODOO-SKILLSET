# Product definition

VOODOO-SKILLSET is a governed AI operations control plane. The user gives a goal; the system selects the smallest high-value capability team, composes a safe DAG, exposes authority gates, executes only through bounded adapters, records evidence, and independently verifies outcomes.

## Surfaces
1. Control Room — command + live DAG.
2. Capability Registry — skills/agents/subagents/plugins/tools/verifiers.
3. Runs & Plans — status, stages, blockers and authority gates.
4. Evidence — hash-chained receipts and verification timeline.
5. Policy Center — authority decisions and risk classes.
6. Runtime Health — tools/connectors availability.
7. Learning — bounded routing signal, never authority.
