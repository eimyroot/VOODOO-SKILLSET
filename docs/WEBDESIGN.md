# Web Control Room design

Dark graphite operations surface, high-density but calm. Status is semantic, not decorative: VERIFIED, BLOCKED, UNKNOWN, APPROVAL REQUIRED.

## Information architecture
- left rail: Control / Intelligence / Trust / System
- top bar: runtime state + active mode
- main: goal composer and dynamic DAG
- right inspector: authority gate, capability rationale, evidence status
- lower panels: evidence timeline, runtime connectors, policy decisions, learning metrics

## UX invariant
The user chooses a goal, not an agent. Every selected worker must explain why it was selected and what authority it has.
